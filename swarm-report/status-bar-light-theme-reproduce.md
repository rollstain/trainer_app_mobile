# Reproduce: белый статус-бар в дневной теме — время и статусы не видны
Платформа: Android
Статус: Воспроизведён (владельцем на живом телефоне, 30.08.2026)

## Входные данные
- Описание: в дневной (светлой) теме системный статус-бар белый, иконки времени/статусов белые —
  не видны на белом фоне.
- Сборка: androidApp-debug после фичи подтверждения почты (сама фича не при чём — тема системная).

## Шаги воспроизведения
1. Телефон в светлой системной теме
2. Открыть приложение (любой экран)
3. → Ожидаемый результат: иконки статус-бара тёмные, читаются на светлом фоне.
   Фактический: иконки белые на белом — не видны.
