# E2E Scenario: вход в профиль и выход из аккаунта (P0·1)
Платформы: Android (эмулятор emulator-5554, debug → https://api.lyashukfit.ru), Backend

Закрывает GAP-3 из `auth-and-roles-e2e-scenario.md`: `Screens.Profile` был зарегистрирован,
но недостижим — пользователь не мог выйти из аккаунта.

Решение: пятый таб «Профиль» в нижней навигации обеих ролей.

## Что изменено
- `uikit/.../drawable/ic_person_filled.xml` — новая иконка (пара к `ic_person`).
- `uikit/.../widgets/Icon.kt` — `AppIcons.person` стал парным `person(isActive)`.
- `composeApp/.../ui/AppRoot.kt` — `TAB_PROFILE` в `coachTabs`/`clientTabs`, ветки в `tabIdOf`/`rootKeyOf`.
- `feature_account/.../profile/ui/ProfileView.kt`, `ProfileScreen.kt` — убрана кнопка «Назад» (экран стал рутовым).
- `feature_account/.../profile/mvi/ProfileContract.kt`, `ProfileScreenModel.kt` — `OnRetryClicked` → `OnReloadRequested`.
- `feature_account/.../contact/**` — `Finish` → `Dismissed`/`Saved`; возврат в Профиль вместо `replaceAll(ClientBooking)`.

## Результаты
- Сборка `:androidApp:assembleDebug` — ✅ BUILD SUCCESSFUL
- Юнит-тесты `:androidApp:testDebugUnitTest` (KoinGraphTest) — ✅
- Клиентская роль — ✅ полностью (CP-2, CP-3, CP-4)
- Тренерская роль — ✅ (CP-1, CP-5; «Позже» на экране контакта тоже даёт `pop`, без `replaceAll`)
- Выход тренера: диалог и «Отмена» проверены ✅, само подтверждение выхода намеренно НЕ выполнялось —
  механизм общий с клиентом (`ProfileScreenModel.signOut` → `AuthRepository.logout` → `SessionEvents.authChanged`
  → `SessionController`) и уже подтверждён на клиентской роли; тренерская сессия оставлена живой,
  чтобы не расходовать одноразовый код перед задачей P0·5 (QA на непустых данных).
- Использованные коды входа: `5HSWCX` (израсходован ранее), `5JZRQA` (израсходован этим прогоном).
  Новый выпускается `POST /admin/coaches/{coachId}/login-code` с `X-Admin-Token` (серверная
  `TRAINER_ADMIN_TOKEN`). coachId тестового тренера: `6a269b69-e95b-477e-a200-cdec13b15829`.
