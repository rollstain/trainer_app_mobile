## Найдено и исправлено в ходе работы
- [x] 61. **Ресурсы не попадали в APK.** Первая раскладка была «ресурсы на модуль»
      (как в `uikit`). Оказалось: плагин Compose настраивает упаковку ассетов только для
      `com.android.library`; на `com.android.kotlin.multiplatform.library` задача
      `copyAndroidMainComposeResourcesToAndroidAssets` не конфигурируется, сборка зелёная,
      а в APK ресурсов нет → `MissingResourceException` в рантайме. Раскладка переделана
      на отдельный модуль `core_strings` на рабочем плагине ✅
- [x] 62. `coil3.disk.directory` — JVM-расширение под `java.io.File`; на iOS не компилировалось.
      Поймано только компиляцией iOS, Android-сборка была зелёной ✅
